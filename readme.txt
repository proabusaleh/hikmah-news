A premium WordPress news portal theme with breaking news, trending algorithm, live search, ad management, and full Gutenberg support.

== Description ==

Hikmah News is a professional, feature-rich news portal theme designed for modern publishers. It includes everything you need to run a successful news website out of the box.

= Key Features =

* 🔴 **Breaking News** — Alert bar, ticker, admin meta, auto-expiry
* ⭐ **Featured News** — Hero, sidebar, spotlight positions
* 🔥 **Trending Algorithm** — Score-based (views + comments + recency + shares)
* 👁 **Post Views** — AJAX tracking, bot-safe, daily analytics
* 🕒 **Reading Time** — WPM calculation + progress bar
* 🔖 **Bookmarks** — AJAX for logged-in, localStorage for guests
* 🔍 **Live Search** — Instant AJAX results, Ctrl+K, keyboard navigation
* ⚡ **AJAX Load More** — Animated infinite scroll
* 🔔 **Push Notifications** — Service Worker, Web Push, auto-breaking
* 📰 **Schema Markup** — NewsArticle, LiveBlogPosting, BreadcrumbList
* 📂 **Category System** — Hierarchical, color-coded, mega menu
* 🏠 **Homepage Builder** — Customizer sections, 4 layouts
* 💰 **Ad Manager** — 13 positions, HTML/image/shortcode, scheduling
* 🔍 **Built-in SEO** — Meta, OG, Twitter Cards, canonical, robots
* ⚡ **Performance** — Lazy load, WebP, critical CSS, CDN, cache
* 🧱 **Gutenberg Blocks** — 11 custom blocks + 5 patterns
* 🌙 **Dark Mode** — Auto/manual/always, full CSS variable swap
* 🌐 **RTL Support** — Arabic, Bangla, Urdu, Hebrew
* 📬 **Newsletter** — Mailchimp, ConvertKit, popup
* 📦 **Import/Export** — Full settings backup/restore

== Installation ==

1. Upload `hikmahnews-theme` to `/wp-content/themes/`
2. Activate the theme through Appearance → Themes
3. Go to Appearance → ⚙️ Theme Options to configure
4. Categories are auto-created on activation
5. Set up menus in Appearance → Menus

== Frequently Asked Questions ==

= Does it work with Yoast/RankMath? =
Yes. Built-in SEO features auto-disable when a SEO plugin is detected.

= Is it compatible with caching plugins? =
Yes. Tested with WP Rocket, LiteSpeed, W3 Total Cache, WP Super Cache, and SiteGround Optimizer. Auto-purge on content update.

= Does it support AdSense? =
Yes. Paste AdSense code in the Ad Manager or use the Advertisement block.

= Is it AMP compatible? =
Yes. Works with the official AMP plugin. Ads and non-essential scripts are hidden on AMP pages.

= Can I use it for a non-English site? =
Yes. Full RTL support and translation-ready (.pot file included).
